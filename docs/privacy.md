# 隐私与数据

记录保存在本机用户目录。开发版与正式版分别使用 %LOCALAPPDATA%\Riji\Development 和 Production，不随源码目录移动。

## 浏览器信息

扩展只处理当前前台 HTTP(S) 网页，排除隐私窗口及浏览器内部页面。不发送完整网址、查询参数或网页正文，不采集网页摘要片段。

当前桌面设置默认开启“记录网页标题”，扩展按桌面下发设置决定是否附带标签页标题。标题可保存到记录中、用于详情及截图识别辅助信息；不希望采集时应关闭此设置。域名用于网站归属规则和时长统计。

## 截图与 AI

启用截图识别并配置 AI 服务后，截图与相应提示词、辅助上下文会发送给所配置的服务。生成摘要、总结或继续对话也会向该服务发送所需记录与对话。数据处理还受所选服务的隐私政策约束。

不识屏模式停止截图及新识别请求。截图保留策略、模型、提示词与标题采集可在设置中调整。

## 备份与设备设置

导出备份含记录、分类、预设、总结、对话及仍保留的关联截图，不含 API Key。备份可能包含敏感活动信息，应自行妥善保管。

当前默认跟随系统主题，并开启开机自启；可以在设置中关闭。自启项指向当前运行的可执行文件。
