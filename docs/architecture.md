# 架构

桌面端以 .NET 10 / WPF 承载 WebView2，界面使用 React 19 与 TypeScript。Windows 集成负责前台应用与系统事件，领域核心处理时间区间和状态，基础设施负责 SQLite、截图任务、AI 与备份。

## 计时与归属

成功识别累计时长与前台应用使用时长分别计算。识别按成功采样的间隔快照累计；应用按有效前台区间累计，不以识别结果补算前台时间。

网站命中规则时，在记录时保存独立统计归属及名称快照，其余浏览器时间归入浏览器。网站时间不重复加入总时长。修改或删除规则只影响之后的记录，历史归属保持不变。

默认、离开、锁定、不识屏是日迹记录状态。“锁定”不是 Windows 锁屏。不识屏停止截图及新识别请求，但可以继续应用计时。离开、系统锁屏、休眠及未知观测空档不能虚增使用时间。

## AI 与记录

截图识别使用可配置提示词、启用的活动分类，以及采样时取得的应用等辅助信息。网页标题受浏览器标题设置控制。分类保留历史快照。

时段摘要可手动生成；整点任务会为上一时段生成摘要，成功后替换该时段已有手动摘要。尚无生成结果时显示占位。AI 总结保存来源、范围、实际提示词与独立对话。

截图在识别结果成功保存后才按保留策略处理。失败任务在 24 小时内重试，网络连接失败时等待服务恢复后再请求；过期或无法恢复的任务标为无效并清理截图，不计入活动时长。无效任务不进入待处理统计。

夜猫子模式可把本地 01:00–09:00 的整点设为新一天起点，默认 05:00，默认关闭。今天、回顾、应用统计与按天 AI 总结使用同一日界。历史归属按原始时间动态计算；跨日界的应用区间按重叠时长分配，原始时间、备份和已生成的总结不改写。活动时间线可选延长小时显示；设置中的任务时间仍使用真实日期时间。

## 浏览器连接

扩展通过本机 HTTP 服务连接：开发环境 127.0.0.1:4177，正式环境 127.0.0.1:4178。使用当前连接握手，无需用户输入配对码。请求来源与扩展身份由桌面服务校验。扩展事件与真实前台浏览器观测共同确定网站区间。
